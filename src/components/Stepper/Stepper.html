Stepper

The steps of a multi-step flow, numbered in order. Four states: Upcoming, Current, Complete (a button that goes back to that step) and Error (a finished step that needs attention). Code-first, built for the Import pattern. Not in Figma yet.

State=Upcoming · Current · Complete

Step 3 is current. Steps 1 and 2 are complete; click one to go back (the demo moves to it).

State=Error

Review found row errors: the step reads as needing attention once the flow has moved past it.

Locked (the run has started)

Every earlier step is done but no longer clickable.

Narrow (container under 640px)

Only the current step keeps a visible label. The others are still read out by screen readers.
