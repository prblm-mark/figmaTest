RoomCard

Summary card for a Seating Planner room. Designer-confirmed as a room/plan card — the componentised form of the planner's plan chip, rather than a new entity above the seating plan, so the name is the plan name and the counts derive from its tables and seats. Presentational only — the parent module owns selection and toggles --selected, so single-select coordination stays with whoever renders the list. No JS in the component.

The whole card is the select trigger: the room name is a real <button> whose ::after stretches over the card, with the edit and delete buttons layered above it so they stay independently clickable. Focus draws a ring around the card rather than around the name.

Types — State=Default

Three types. Default and Seats Assigned are the same CSS — Figma draws them as separate variants, but they differ only in the data driving the bar and the label, both brand-coloured. Only --full changes anything visually: the bar turns --ai-surface-success and the FULL badge replaces the seats-free text.

Device=Mobile

Resize the viewport below 768px to see the mobile layout. Figma's Device axis is implemented as @media (max-width: 767px), not a modifier class, so the cards above respond on their own. Four things change: padding 16px → 12px, min-width 280px → 240px, the room name 16px → 14px, and the word "seated" leaves the counts line. It stays in the accessibility tree, so screen readers still hear the full sentence.

Long room name

The name is the only flexible element in the header; it truncates with an ellipsis so the edit and delete buttons never get pushed out of the card.
