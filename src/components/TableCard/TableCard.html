TableCard

Table summary card for the Seating Planner tables grid. Shows a table's name, tier, sponsor and a per-role capacity breakdown. Presentational only — the parent module owns selection and toggles --selected; selecting a table is what opens Table Detail. No JS in the component.

The header is a column: the table name and tier pill share a row with a 12px gap, and the sponsor row sits beneath them spanning the full card width. The name wraps rather than truncating.

The whole card is the select trigger: the table name is a real <button> whose ::after stretches over the card, with the edit and delete buttons layered above it so they stay independently clickable. Composes TableType, FullBadge and Button.

The capacity bar is proportional to the seat counts: each segment carries its count in a --seg custom property and divides the track by flex-grow. Figma draws the segments at fixed widths that contradict its own legend, so those widths are not ported.

State=Default

Three Types. The whole Type axis is data, not CSS — Empty, Populated and Full differ only in how many bar segments and legend rows the caller supplies, and whether the FullBadge is present. Nothing branches on Type, so there are no --empty / --populated / --full modifiers.

Device=Mobile

Resize the viewport below 768px to see the mobile layout. Figma's Device axis is a @media (max-width: 767px) rule, not a modifier, so the cards above respond on their own. Only two things change: padding 16px → 12px and the table name 16px → 14px. Unlike RoomCard the min-width does not step down, and the bar, legend, swatches, badge and buttons are all identical between breakpoints.
