TableDetail

Table inspector panel for the Seating Planner — a 320px rail listing every seat at a table. Tier: Pattern. Composes AttendeeCard (one per seat), TableType for the tier pill, and Button via AttendeeCard's Assign action. Presentational only — the seat rows are drop targets whose --dragged-over the parent module toggles; nothing here drags, and there is no JS.

The panel fills its column and the seat list scrolls inside a fixed header. Figma pins the desktop panel at 698px, but that is just how tall it drew ten seats — a twenty-seat table has to work too, so the height comes from the container instead. Each demo below is bounded to 560px to show that scroll.

The whole Type axis is data, not CSS. Default, 2 Roles, All Roles and Full differ only in how many roles the legend lists and how many seats are filled — so there are no Type modifiers, exactly as with TableCard.

Type=Default

No legend at all — nothing is seated, so there are no roles to list. Ten Empty seats.

Device=Mobile

Resize the viewport below 768px. All four mobile variants drop the panel header entirely — no table name, seated count, sponsor or tier pill — and tighten the list: padding 16px → 8px and the seat gap 8px → 6px. The mobile screen supplies the table name in its own sheet chrome. Implemented as @media (max-width: 767px), so the panels above respond on their own.
