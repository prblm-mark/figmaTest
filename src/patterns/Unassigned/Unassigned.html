Unassigned

Tray of attendees not yet seated, for the Seating Planner. Tier: Pattern — Figma defines no Tier property on this set, unlike the rest of the module, but it composes two components so §4 puts it here.

Composes AttendeeCard with both of its booleans off — no seat number and no row actions, since an unseated person has no seat to number and nothing to reorder — and Input (input input--sm, label-less, leading search icon). Presentational only, no JS: in the real module these rows are the drag sources that the seat rows receive, and the parent owns that.

The Type axis is data. Default is the empty state and Unassiged [sic] is the populated list, so which one renders is markup the caller supplies — there are no Type modifiers, just different children of __body.

Both types

The count pill and the hint line are identical in both; only the body below the search field changes.

No mobile variant

Figma defines no Device axis on this set — only Type — and the word “mobile” appears nowhere in its design context or variables, so there is no mobile layout to implement. The panel is a fixed --ai-size-6 (320px) rail at every width, like TableDetail.
