Toolbar at mobile — options to review Open

The action bar wraps to three ragged lines below 640px. Its cause is precise rather than general crowding: .sp-toolbar__spacer is flex: 1 in a wrapping row, so on a wrapped line it collapses to 4px instead of forcing a break — which is why “Only free seats” sits against the title rather than with the controls. Three options built as working files; start with the compare board, which carries the measured numbers and the trade-offs. Scope note: the toolbar is 112px of the 496px above the first table card, so none of these fixes more than a fifth of the mobile problem — the 274px event bar is the bigger offender and is still untouched.
