    These settings apply to every row in the file.

    Import type

    Full user creates or updates contacts. User topics adds topics to matching contacts (the topics must already exist). Contact notes adds notes to matching contacts.

    Action

    On Update, a blank cell leaves that detail as it is. Passwords can't be updated. Contacts are matched by UserCode, then External ID, then Email.

    Your name for this batch, so you can add to it later or delete it with User Batch Delete.
    Registration zone

    The zone's user, registration and demographic profiles are used for the imported details.

    The security groups imported contacts are placed in.

    The account the contacts are assigned to. Update moves existing contacts to this account.

    Imported contacts are added to these contact lists.

    Store credits

    Add puts the column's points on top of each contact's balance. Update replaces the balance, so check nobody has spent credits since the file was made.

    Leave blank to start at row 2 (row 1 is the column names). One run imports up to 10,000 rows; for a bigger file, import it again with the next start row.
    Leave blank to import to the end of the file, up to 10,000 rows per run.
