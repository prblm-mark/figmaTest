CRM API version 1

REST API security

  • all requests must be under ssl
  • every request must be signed
  • signature check (same signature can't be used for 30 minutes)
  • valid user agent must be provided

Signature in the request header will be used for every call to authenticate the request. The API Key and API Secret will be from the API Profile.

Signature calculation example

For this example calculation the following is used:
Sitename: AffinoDemo
Key: 49yRcAR9J9
Secret: Oug82Izd6Cz2G7f2k6o4tr2Ma9D511

The signature is created as

signature string = HTTP Method + URI Pattern + Body MD5 + API Secret + timestamp

Note: if the body is empty it is not used in the signature calculation (in this case the signature string = HTTP Method+URI Pattern++API Secret+timestamp)

HTTP Method = GET
URI Pattern = /rest/AffinoDemo/crm/v1/accounts
Body = {"StartCode":"0"}
timestamp = 2018-06-20T14:09:12Z

body MD5 = 6471D2C7B7D2C824C638E6EB0A75FB4D
signature string = GET+/rest/AffinoDemo/crm/v1/accounts+6471D2C7B7D2C824C638E6EB0A75FB4D+Oug82Izd6Cz2G7f2k6o4tr2Ma9D511+2018-06-20T14:09:12Z

for the hash we will use SHA-512

Accounts

List Accounts

GET/rest/Comrz/crm/v1/accounts

returns a json structure with accounts.

  • Request parameters
    • StartCode (numeric/not required) : StartCode to start the data with (eg if set to 10 only records with AccountCode greater that 10 will be returned )
    • Search (string/not required) : Will match the search sting against account name
    • DateFilter (datetime/not required) : Will return records created or updated after specific date (date format YYYY-MMM-DD HH:MM:SS)
  • Response parameters
    • TotalRecords : total records of accounts matching the search criteria
    • LastRecordCode : last AccountCode returned in the response
    • CurrentDate : current site date
    • Accounts : the structure with accounts (max 20 records returned per a call, to get all records the StartCode parameter needs to be used)
      • AccountCode (numeric) : account unique Code
      • ExternalAccountID (string/50) : external account ID
      • Name (string/255) : account name

  • Request
    • MethodGET
    • Urlhttps://www.affino.com/rest/Comrz/crm/v1/accounts?StartCode=0&Search=Test
    • Header

      • LastName (string/100) : users last name
