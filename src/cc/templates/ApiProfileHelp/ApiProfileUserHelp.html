User API version 1

REST API security

  • all requests must be under ssl
  • every request must be signed
  • signature check (same signature can't be used for 30 minutes)
  • valid user agent must be provided

Signature in the request header will be used for every call to authenticate the request. The API Key and API Secret will be from the API Profile.

Signature calculation example

For this example calculation the following is used:
Sitename: Comrz
Key: 49yRcAR9J9
Secret: Oug82Izd6Cz2G7f2k6o4tr2Ma9D511

The signature is created as

signature string = HTTP Method+URI Pattern+Body MD5+API Secret+timestamp

Note: if the body is empty it is not used in the signature calculation (in this case the signature string = HTTP Method+URI Pattern++API Secret+timestamp)

HTTP Method = POST
URI Pattern = /rest/Comrz/login
Body = {"Email":"julius@affino.com","Password":"password"}
timestamp = 2019-01-18T09:48:45.224Z

body MD5 = 2CD183EC0BD817D168F39EB489E6A32B
signature string = POST+/rest/Comrz/login+2CD183EC0BD817D168F39EB489E6A32B+Oug82Izd6Cz2G7f2k6o4tr2Ma9D511+2019-01-18T09:48:45.224Z

for the hash we will use SHA-512
hashed signature: 179872E60C2265B13FDB3BA46224F97143E0B514B175C613E16735D0B6613EC04C892BF8629C488BF6F85AC53EDE4FDF35AD9FFF89E131959893C4DC6DF02810
