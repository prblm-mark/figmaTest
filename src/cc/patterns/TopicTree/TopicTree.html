Default · collapsed, levels load on demand

The topic list's top level (topics with no parent), A–Z. A chevron expands a topic; its children load the first time (a short delay here, so the loading row shows). The name, or anywhere else on the row, opens the topic; the pencil edits it. Keyboard: ↑ ↓, → expand / step in, ← collapse / step out, Home, End, Enter.

Expanded · 8 levels deep

The deepest real branch on Affino's own list: Solutions › Affino › Content Management › Website Management › Design › Display › Display Format › Text Size. Each level indents 32px (--ao-spacing-7), so a child's chevron sits under its parent's name; the name truncates rather than the counts.

Multi-parent · "also under"

Accessibility sits under Website Management AND under Standards, so it appears in both places. The link icon names the other parent (hover it, or focus the row). The second link is invented for the demo; the schema allows any number.

Search · matches with their ancestors

Topic contains "image": every match is shown with the path that leads to it, opened. Ancestors drawn only for context are muted (--ao-text-secondary); matches keep the row's own colour.

Show more · per-level cap

v1 caps a level at 300 topics. The cap here is 10 so it shows: the rest of the level is one click away, and the count says how many are drawn.
