Stepper

.input--stepper — a number field with − / + buttons. The native spinner is hidden, since the buttons replace it. Buttons disable at the bounds, so the control cannot produce an invalid value; typing or arrow-keying past a bound updates them too. Each press emits input and change, so validation and bindings react as they would to typing.
