AttendeeCard

Attendee row for the Seating Planner — used in the Unassigned tray and inside Table Detail. A drop target only: it never initiates a drag, and --dragged-over is a class the parent module toggles while an attendee is held over it. No JS in the component.

Role colours come from the Seating Planner collection. Radix Vivid is the default, so the card works with no extra markup; add data-seating="muted" or "radix-soft" to an ancestor to switch palette. The section at the foot of this page shows all three.
