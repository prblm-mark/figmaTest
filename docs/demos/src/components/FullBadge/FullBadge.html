FullBadge

Status pill for a seating container that has reached capacity. Used by RoomCard and TableCard, where it replaces or sits beside the seats-remaining text once nothing is free.

Single-purpose by design. Figma defines exactly one appearance, so there are no variants, sizes or colour modifiers — and none should be added without a Figma counterpart. It was extracted from two identical inline Figma frames rather than built from a component set; see the notes for what that means for Code Connect.

Legibility

The badge is 9px type with a 10px check — small enough that the check's stroke weight matters. Shown at 1×, 3× and 6× so the icon weight can be judged; the 1× instance is the real rendering, the others are scaled copies.

Known contrast issue

White on --ai-surface-success measures 3.16:1, under the 4.5:1 that WCAG AA requires for 9px bold text. This needs a palette answer — a darker success or a dark label — rather than a component fix, so it is deliberately open at the designer's direction, tracked in docs/contrast-audit.md. Fixing it here now fixes it for both consumers at once, which is part of why this was extracted.
