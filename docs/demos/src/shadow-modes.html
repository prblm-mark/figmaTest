Shadow modes

Every shadow token, on every surface it lands on, in all six modes. The shadow tokens themselves only define :root and [data-theme="dark"] — so switching to CC or Chat does not change the shadows, it changes the surfaces underneath them. That is the interesting part: Chat still runs on the older warm greys while the default context is on the slate ramp.
